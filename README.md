# knACK Cyber website

Single-page site for knACK Cyber: cloud security, finding normalization, private AI security, audits, and Partner Advisory.

- `index.html` is the whole site. The logo is inlined as SVG and fonts (JetBrains Mono, IBM Plex Sans) load from Google Fonts.
- `assets/logo/` holds the brand logo files (SVG, PNG, PDF).

## Hosting

Turn on GitHub Pages (Settings → Pages → deploy from `main`, root) to publish at `https://itsnotjason.github.io/knackcyber/`.
